WBench-Robo: Worlds That Respond To Action

From watching a world to making something happen in it.

Explore the idea ↓All research ↗

Project Preview · The project name is supplied by the team. The description below is illustrative copy for this website preview.

On this pageOverviewInteraction brings new constraintsLook beyond the final frameQuestions for embodied worlds

For an embodied agent, visual realism is only a starting point. The world also needs to respond when the agent reaches, pushes, lifts, or changes its point of view. That response is where a useful model of the physical world begins.

Interaction brings new constraints

Manipulation connects geometry, motion, and causality. A hand should make contact before an object moves. A lifted object should remain supported. A change in viewpoint should reveal the same arrangement of objects.

This preview positions WBench-Robo as a study of those connections. The focus is on how an action changes a scene, and whether the resulting state can support the next action.

Look beyond the final frame

Reaching a plausible-looking end state is not enough to explain how a task unfolded. Intermediate states can reveal missed contacts, inconsistent geometry, or an action that never meaningfully affected its target.

A proposed evaluation would inspect the interaction trajectory alongside the final state. This makes room for questions about controllability and physical plausibility without treating visual similarity as a complete measure of success.

Questions for embodied worlds

01

Does contact happen where and when the action requires it?

02

Do objects preserve their identity and geometry during manipulation?

03

Is the resulting state consistent with the next intended action?

A useful world model should make actions matter.
