AgentMemory: Remembering What Matters

Useful memory is selective, grounded, and ready to be revised.

Explore the idea ↓All research ↗

Concept Preview · This is a sample project with illustrative copy, created to preview the FudanCVL Robotics website.

On this pageOverviewRemember with a purposeLeave room for changeQuestions for persistent agents

A longer context is not automatically a better memory. Agents need to distinguish a stable preference from a temporary fact, a verified observation from an assumption, and a useful lesson from an irrelevant detail.

Remember with a purpose

AgentMemory is an illustrative project concept about selecting and retrieving context for ongoing work. The question is not simply what an agent can store, but what it should bring back into a new situation.

A memory can be useful when it captures why a decision was made, which source supported a fact, or what constraint mattered in an earlier task. Keeping those connections can make later use easier to assess.

Leave room for change

Stored context can become stale. A configuration changes, a project moves, or a previous observation no longer applies. Memory therefore needs a way to preserve uncertainty and respond to new evidence.

This concept explores retrieval alongside revision. Rather than treating a remembered statement as permanently true, an agent could use it as a starting point for deciding what needs to be checked now.

Questions for persistent agents

01

Is retrieved context relevant to the current objective?

02

Can an agent distinguish a durable preference from a changing fact?

03

Does new evidence update an earlier conclusion rather than silently contradict it?

Remembering well also means knowing what to revisit.
