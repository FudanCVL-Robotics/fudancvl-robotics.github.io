WBench-Long: Beyond The Next Few Seconds

What does a generated world remember after you leave it behind?

Explore the idea ↓All research ↗

Project Preview · The project name is supplied by the team. The description below is illustrative copy for this website preview.

On this pageOverviewThe horizon changes the questionReturn, revisit, rememberQuestions worth measuring

A world can look convincing for a moment and still lose its identity over time. Longer interactions ask more of a model: remember what has changed, preserve what has not, and make the next action fit the history that came before it.

The horizon changes the question

A short clip can hide a broken connection between cause and effect. A doorway may change shape when revisited. An object may return after it was moved. A local motion can remain smooth while the larger environment drifts.

This project preview frames WBench-Long around those delayed failures. The emphasis is on continuity across an interaction, with checkpoints that connect earlier choices to later observations.

Return, revisit, remember

A useful evaluation can ask a model to move through a scene, modify something, explore elsewhere, and return. The return journey gives memory a concrete meaning: the same place, the same object, and the consequences of the same action.

The proposed analysis separates immediate response from longer-term persistence. Looking at both helps distinguish a visually strong moment from a world that remains coherent over time.

Questions worth measuring

01

Does an environment remain recognizable after an extended exploration?

02

Are earlier changes still present when a location is revisited?

03

Can a model recover coherently after a difficult or ambiguous interaction?

A longer horizon makes memory visible.
