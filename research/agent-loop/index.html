AgentLoop: Planning Is Only The Beginning

Good plans need a way to learn from what actually happens.

Explore the idea ↓All research ↗

Concept Preview · This is a sample project with illustrative copy, created to preview the FudanCVL Robotics website.

On this pageOverviewKeep the plan connected to realityMake recovery part of the taskWhat makes a loop useful?

An agent does not act in a static description of the world. Tools return unexpected results, assumptions become outdated, and a task can change while it is being carried out. Reliable behavior depends on closing the gap between a plan and the evidence produced by each action.

Keep the plan connected to reality

AgentLoop is an illustrative research concept centered on a repeated cycle: form a plan, take a bounded action, inspect the result, and revise. The next step is grounded in the latest observation rather than in an earlier expectation.

This framing makes a distinction between a tool call completing and a task actually succeeding. A useful feedback loop needs evidence for the outcome that the agent was trying to achieve.

Make recovery part of the task

Unexpected results are not always terminal failures. They can be signals that an assumption was wrong, that a different tool is needed, or that the agent should narrow its next step.

The concept explores how agents could recognize these signals and recover while respecting the original objective. An informative evaluation would examine both the final outcome and the path taken to reach it.

What makes a loop useful?

01

Does the agent inspect the consequences of its actions?

02

Can it revise a plan when new evidence contradicts an assumption?

03

Does it recognize when a task is complete, or when more information is needed?

A plan becomes useful when it stays open to evidence.
