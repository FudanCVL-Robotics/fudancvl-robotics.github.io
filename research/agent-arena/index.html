AgentArena: Evaluating The Work Between Request And Result

An answer is one artifact. The work behind it is another.

Explore the idea ↓All research ↗

Concept Preview · This is a sample project with illustrative copy, created to preview the FudanCVL Robotics website.

A useful agent needs to translate a request into actions, work with imperfect information, and leave behind a result that can be checked. Evaluating that process calls for more than judging a final sentence.

Start with a task, not a prompt trick

AgentArena is a concept preview for an evaluation setting built around multi-step work. A task might involve finding information, organizing a workspace, making a bounded change, or checking that a requested outcome is present.

The central idea is to define observable completion conditions. That makes the evaluation less dependent on how confidently an agent describes its own work.

Examine the path as well as the destination

The same final artifact can be produced through careful verification or a series of unsupported assumptions. Process evidence can help separate these behaviors by showing which actions were taken and what information was available at each step.

This concept considers reliability, recovery, and instruction adherence alongside outcome quality. It is a proposed research framing, rather than a released benchmark or a set of measured results.

What should a task reveal?

01

Can completion be verified from the resulting environment or artifact?

02

Does the agent preserve constraints throughout a longer task?

03

What changes when tools fail or necessary information is missing?

Evaluate the work, not just the claim that it is done.
